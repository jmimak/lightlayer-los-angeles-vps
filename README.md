## “50M优化/200M全向/300M国际”到底指什么

这是LightLayer独立服务器页面上标的带宽，三档并列，不是三个可以随便挑的数字。优化档一般指面向中国大陆方向的优化线路，全向档是通用方向，国际档面向海外访问。同一台机器三个方向的上限不同，你主要用户在哪，就该看哪一档。

这和VPS页面常见的“1G优化”“10M优化”是两套写法。前者是端口速率还是保证带宽，官方没在促销页写死；后者直接把优化方向标出来。买之前要确认三件事：这个数字是端口峰值还是保证带宽、流量是否双向统计、超量之后是限速还是停机。促销页对圣何塞款只写了“1T/月”，新加坡款写“不限”，洛杉矶和香港独立服务器没标月流量，这些都要以套餐详情页为准。

带宽这个词在不同商家嘴里含义差很多，同一个“500Mbps”可能指端口峰值，也可能指保证带宽。LightLayer至少把优化、全向、国际分开标了，比笼统写一个数字清楚，但仍然要在下单页核对。
